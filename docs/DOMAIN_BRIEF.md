# Signal School domain brief

Signal School is a private-preview learning product for checking an AI-assisted draft before sharing it. Its primary entry is the Workroom: a browser-only place to keep a request, source notes, a pasted draft, selected claim checks, and a handoff together. Three substantial fictional practice cases cover a supplier decision, release readiness, and an incident update. Six short authored exercises remain available under Learn, and the original source-aware cases remain in the separate Final challenge workspace.

The product teaches a repeatable route: state the request, keep relevant evidence attached, check the claims that matter, and give another person a handoff they can inspect. It does not claim that selected checks prove a whole document is correct, that a learner is certified, or that an AI system is being assessed.

## Product boundaries

- Exercise feedback comes from authored deterministic answers and references, never a model or keyword scoring.
- Workroom claim findings and acceptance criteria are recorded by the user. Fictional reference judgments appear only for an unchanged practice case; own work is always manual.
- A practice reference reports conflicting saved judgments explicitly. A positive match requires every saved check of that draft passage to cover the reference verdict and excerpts.
- Markdown handoffs preserve authored text as literal labelled content, including earlier snapshots. Pasted formatting cannot become a status or heading supplied by the app.
- Editing a brief, source note, criterion, or draft archives the existing reviewed version and clears the current decisions. Earlier versions remain distinguishable from the current material.
- A partly completed claim check is visibly unfinished and is never silently included in a handoff. Downloading offers a save, return, discard, or explicit without-it choice.
- Changing a meaningful Workroom, opening a valid handoff over it, clearing it, or resetting the course asks the person to keep editing, download first, or continue deliberately. Pristine practice cases can still be changed directly.
- Inputs, XP, answers, and feedback remain in browser memory and clear on refresh or reset.
- Copy and downloads are explicit browser actions. A versioned JSON handoff can be opened only after strict validation. The product sends no work, makes no network request, and stores no learner profile.
- A changed exercise or case answer clears displayed feedback. XP can be earned once per exercise until reset and must never imply that a changed answer remains correct.
- The course uses fictional situations. It is learning material, not a workplace guarantee, legal advice, or a capability claim.

## Experience direction

The interface should feel like a calm signal-routing workbench: deep ink, electric cyan for active paths, and a restrained warm accent for earned progress. Lead with the first useful task: start a practice case, begin your own work, or check the loaded draft. Keep the Workroom compact enough that its action and steps are reachable on a phone, while retaining keyboard operation, visible focus, and no essential motion from 320px through desktop widths.
